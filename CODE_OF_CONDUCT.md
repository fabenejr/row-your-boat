# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming. Critique ideas and code, not people.
- No harassment, insults, discriminatory language or personal attacks.
- Assume good intent and help newcomers. Everyone was new to modding once.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests that break these rules,
and may temporarily or permanently ban contributors who repeatedly do so.

To report a problem privately, contact the maintainer through their GitHub profile
([@fabenejr](https://github.com/fabenejr)). Reports are handled confidentially.
