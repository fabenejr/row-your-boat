# Security Policy

## Supported versions

Only the latest release of Viking Oarsmen receives fixes. Please update before reporting.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately instead:

1. Go to the [Security tab](https://github.com/fabenejr/row-your-boat/security) of the repository.
2. Click **Report a vulnerability** and describe the problem, how to reproduce it and the mod version.

You can expect an answer within a few days. Once a fix is released, the report is disclosed in the
[CHANGELOG](CHANGELOG.md) and credited to you if you wish.

## Scope

Viking Oarsmen is a client-side BepInEx plugin. Examples of what is in scope: crashes or desyncs that another
player can trigger remotely, and anything that lets a remote player write to a ship or ZDO they do not own.
Bugs in Valheim, BepInEx or other mods should be reported to their own projects.
